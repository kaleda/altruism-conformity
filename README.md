# altruism-conformity
This repository contains code for the paper ["Conformity and content-biased cultural transmission in the evolution of altruism"](https://www.sciencedirect.com/science/article/pii/S0040580921000745) published in *Theoretical Population Biology* (previously posted as a preprint titled "Oblique Transmission, Conformity, and Preference in the Evolution of Altruism") by Kaleda K. Denton, [Yoav Ram](https://github.com/yoavram), and Marcus W. Feldman.
